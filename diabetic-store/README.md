# Dodoliza — Diabetic Socks Store (v1 design build)

Premium Arabic-first (RTL) store that sells only diabetic socks. Saudi Arabia, prices in SAR. English toggle in the header.

## Pages
| File | Page |
|------|------|
| `index.html` | Home: hero, why diabetic socks, product lineup, size guide, testimonials (placeholders), trust strip, FAQ |
| `shop.html` | Shop with filters: length, color, size, pack size (3/6/12) |
| `product.html` | Product: gallery with zoom, size chart modal, pack selector with per-pair savings, sticky add-to-cart on mobile, doctor note |
| `cart.html` / `checkout.html` | Cart and one-page guest checkout with cash on delivery (front-end only, `noindex`) |
| `about.html`, `contact.html` | Our story; contact + floating WhatsApp button |
| `banners.html` | Homepage hero + Instagram post/story + Facebook ad banners (`banners/*.png`) |

## Stack
- Plain HTML + Tailwind Play CDN (`3.4.17`, preflight off) + `assets/app.css` components.
- Design tokens: `assets/tokens.css` (primitive → semantic → component).
- Fonts: Cairo (Google Fonts).
- Behaviour: `assets/app.js` (language toggle, cart in localStorage, filters, gallery, checkout validation). Product data: `assets/data.js` (generated).
- Pages are generated by `build.py` (`python3 build.py`). Edit `PRODUCTS`, `PACKS`, `FAQ`, `WA` at the top, then rebuild.

## For the developer — what is placeholder
- All product names, prices (89 / 159 / 289 SAR), material composition, return policy, WhatsApp number (`966500000000`), email, working hours.
- All product/lifestyle images are an illustrated sock placeholder with a "placeholder" tag.
- Testimonials are marked as placeholders.
- Cart/checkout do not submit anywhere; connect to the real store (WooCommerce / Salla / Shopify) and payment gateway.
- For production, replace Tailwind Play CDN with a compiled Tailwind build.

## SEO
Every page has title, meta description, canonical, hreflang, Open Graph and JSON-LD:
Organization + WebSite + FAQPage (home), CollectionPage + ItemList + BreadcrumbList (shop), Product (AggregateOffer, SAR) + FAQPage + BreadcrumbList (product), AboutPage, ContactPage. Cart and checkout are `noindex`.
